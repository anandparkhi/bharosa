# Security and privacy
Coach does not invoke LLM; reviewed task allowlist. Never request OTP/PIN/password, transfer money, remote control a device or infer helper approval. Manual helper sharing requires contact selection and checked opt-in; user must send WhatsApp draft themselves. History local only, bounded and deletable. Existing scam check sends volunteered text/image to service and Anthropic. Origin check is not authentication; memory rate-limiting not a distributed abuse defense. New institutional product requires lawful basis, purpose-specific notice, retention controls, processor assessment, authentication and separate consent. Review applicable Indian DPDP framework from MeitY: https://www.meity.gov.in/documents/act-and-policies?persona=It-professional . No compliance certification asserted.
