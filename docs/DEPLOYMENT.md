# Build, release and rollback
Use Node 22, `npm ci`, `npm run check`, `npm run dev`, and `npm run build`. The Anthropic API key must be server-side as `ANTHROPIC_API_KEY` (never `VITE_` exposed); model override `ANTHROPIC_MODEL` as supported by existing code. Vercel processes `api/ai.ts` as a serverless function with rewrites in `vercel.json`. Never merge or production-deploy until founder approval. Validate draft PR #2 preview first; capture live device evidence; revert to previous Vercel deployment on regression. Avoid publishing screenshots of real users' private messages. CDN/background PWA caches need verification during rollback.
