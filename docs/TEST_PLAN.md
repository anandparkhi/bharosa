# Test Plan
Run `npm ci && npm run check && npm audit --omit=dev --audit-level=high`. CI workflow `.github/workflows/verification.yml` triggers on feature branch and PR. Unit tests `tests/coach.test.mjs` exercise 6×2×3 guide variants, out-of-scope tasks, history schema and bounded count, outcome denominators, minimally scoped sharing. Independent browser tests: Android Chrome & iOS Safari, 320px, 200% font, TalkBack/VoiceOver, English/Hindi/Marathi, permission denied, storage quota denied, navigation away, offline, unfamiliar device OEM. API adversarial: model prompt injection, cross-origin direct HTTP, abuse rate limits, screenshot invalid format, false reassurance and provider timeout. No device/AI accuracy results claimed without logs.
